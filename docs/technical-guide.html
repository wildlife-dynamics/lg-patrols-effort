Technical Guide

A deeper look at how the LG Patrols Effort Workflow is built: the EarthRanger ingestion pipeline, map and chart methodology, summary metrics, and report assembly.

Download the full Technical Guide (PDF)

This guide was cross-checked line-by-line against spec.yaml. Several claims in the previous version were inaccurate — most notably, the study-area boundaries are fetched live from EarthRanger (not downloaded from Dropbox as a Conflict Hotspots + Group Ranch Boundaries pair), patrol trajectories use a single fixed colour rather than a user-selectable colour category, and several task names and a cover-page filename were wrong. This workflow has also migrated to the consolidated ecoscope-platform package.
